# 🎵 Tarang

### A music streaming experience designed to feel magical.

Tarang is a premium music streaming web application focused on beautiful interfaces, smooth motion, and immersive listening experiences.

- Floating music player
- Responsive UI

- Queue

## 🛠 Tech Stack

- Next.js

- TypeScript
- Tailwind CSS
