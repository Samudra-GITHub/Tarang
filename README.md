# 🎵 Tarang

### A music streaming experience designed to feel magical.

Tarang is a next-generation music streaming web app built around **beautiful UI, smooth motion, and thoughtful user experience** instead of a traditional dashboard-first approach.

> *Music isn't just something you play. It's a world you step into.*

---

## ✨ Current Status

**Version:** `R0.2`

# ✨ Design Philosophy

Tarang follows one simple principle:

> **Minimal interface. Maximum emotion.**

Instead of copying Spotify or Apple Music, Tarang focuses on creating a calm, immersive listening experience with thoughtful motion, soft glass surfaces, and beautiful artwork.
